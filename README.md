# 📊 Dashboard de Bienestar Adolescente – Proyecto en Excel

Este proyecto presenta un análisis exploratorio y visualización de datos sobre el bienestar emocional de adolescentes, basado en un conjunto de datos diarios de salud mental. El objetivo es identificar patrones y relaciones relevantes entre factores como el estado de ánimo, el nivel de estrés, las horas de sueño, el uso de pantallas y la práctica de actividades saludables como el journaling o la meditación.

## 📁 Estructura del proyecto

modern_teen_mental_health_main: hoja con los datos originales más columnas derivadas creadas con fórmulas en Excel.
Tablas dinámicas: hoja que contiene las tablas dinámicas base para la visualización.
Dashboard: hoja visual e interactiva que resume los principales KPIs e insights.
⚙️ Transformaciones aplicadas

Se añadieron columnas calculadas en Excel para facilitar el análisis:

well_being_score: indicador compuesto de bienestar.
weekday y month: segmentación temporal.
sleep_range y screen_time_range: agrupaciones interpretables para análisis de hábitos.

# 📌 Principales indicadores visualizados

Promedios de mood, stress_level, sleep_hours y well_being_score.
Comparaciones por género, día de la semana y uso de IA.
Análisis de hábitos: pantallas, sueño, journaling, meditación y ejercicio.

# 🧩Herramientas utilizadas

Microsoft Excel 100% 
Fórmulas nativas y tablas dinámicas
Gráficos de columnas, barras, líneas y dispersión
Segmentadores y diseño responsivo en hoja Dashboard

# 📈 Objetivo del dashboard

Proporcionar una herramienta interactiva y comprensible para visualizar y explorar los factores que influyen en el bienestar adolescente. Este tipo de visualización puede resultar útil para docentes, psicólogos, investigadores o responsables de programas escolares.
